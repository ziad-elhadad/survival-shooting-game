# Assets Directory

This directory contains game assets organized into subdirectories:

## Structure

- **images/**: Background images, UI elements, and static graphics
- **sounds/**: Sound effects and background music
- **sprites/**: Character sprites and animations

## Adding Assets

To add your own assets:

1. Place images in the `images/` folder
2. Place sound files in the `sounds/` folder
3. Place sprite sheets in the `sprites/` folder
4. Reference them in your JavaScript code

## Supported Formats

- **Images**: PNG, JPG, SVG
- **Audio**: MP3, WAV, OGG
- **Sprites**: PNG with transparency

## Notes

- Keep file sizes reasonable for web performance
- Use descriptive filenames
- Consider using sprite sheets for animated characters
